# Harness Guidelines

## Core Principles

1. **Reliability over Autonomy**
   Agents operating within this harness are strictly prohibited from hallucinating selectors, test data, assertions, or API endpoints. Certainty is paramount.

2. **Single Responsibility Agents**
   - **Explorer:** Gather evidence.
   - **Builder:** Construct tests.
   - **Runner:** Execute tests.
   - **Debugger:** Analyze failures.

3. **Artifact-Driven Communication**
   Agents must communicate *only* through structured JSON artifacts. No free-form summaries. Each agent reads the predecessor's artifact before acting.

4. **100% Traceability**
   Every action or test step generated by the Builder Agent must reference a source URL and a verified selector gathered by the Explorer Agent. 

5. **Stop on Low Confidence**
   If confidence drops below 95% at any stage, the agent MUST STOP and return an error state (`MISSING EVIDENCE` or `INSUFFICIENT_EVIDENCE`).
